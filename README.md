# Web Development Practicals

This repository contains practice examples for HTML, CSS, browser JavaScript,
and Node.js.

## Run the collection

Install Node.js 18 or newer, then run:

```text
npm start
```

Open <http://localhost:8080> in a browser. The landing page links to the main
example folders.

The server uses only Node.js built-in modules, so no `npm install` is required.

## Node.js examples

The files under `JAVASCRIPT/NODE JS` are independent practice programs. Many
Express and database examples require their own dependencies and should be run
from their containing folder after installing the dependencies used by that
example.

The file `JAVASCRIPT/NODE JS/Authorization/A14.java` is a Java REST client,
not a JavaScript file.
